# 🎬 The Eltingville Club — Fan Site

Um site não oficial dedicado ao universo de **The Eltingville Club**, obra criada por Evan Dorkin, conhecida por sua sátira da cultura geek, do colecionismo e das rivalidades entre fãs.

## 📖 Sobre o projeto

O projeto apresenta informações sobre o universo de *The Eltingville Club*, seus personagens, sua história e suas publicações. O site utiliza uma identidade visual inspirada em quadrinhos underground, com cores escuras, vermelho, amarelo e elementos gráficos que remetem às páginas de HQs.

A proposta é reunir informações sobre a obra em uma experiência visual interativa, desenvolvida com HTML, CSS e JavaScript.

## ✨ Funcionalidades

- 🏠 **Página inicial:** apresentação da obra e de sua identidade visual.
- 🌎 **Universo:** contexto, características e principais temas da história.
- 👥 **Personagens:** apresentação dos quatro integrantes do clube, com fichas interativas.
- 📅 **Linha do tempo:** principais acontecimentos e etapas da publicação.
- 📚 **Publicações e animações:** seção dedicada aos quadrinhos, às coletâneas e ao piloto animado.
- 🖼️ **Imagens:** suporte para fotografias e imagens de capas.
- 📱 **Design responsivo:** adaptação para computadores e dispositivos móveis.
- 🎨 **Identidade visual:** textura de papel, cores contrastantes, tipografia marcante e elementos inspirados em quadrinhos.
- ⚡ **Interatividade:** menu responsivo, janelas de perfil e animações durante a navegação.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura e organização do conteúdo.
- **CSS3:** estilização, layout responsivo, efeitos visuais e animações.
- **JavaScript:** interações, menu de navegação e fichas dos personagens.

## 🚀 Como executar

1. Faça o download ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Confira se os arquivos HTML, CSS e JavaScript estão organizados corretamente.
4. Coloque as imagens utilizadas na pasta `imagens`.
5. Abra o arquivo `index.html` no navegador.

Para facilitar o desenvolvimento, você pode utilizar a extensão **Live Server** do Visual Studio Code.

## 🎨 Personalização

O projeto permite modificar cores, textos, imagens e efeitos visuais.

- Para alterar o conteúdo, edite o arquivo `index.html`.
- Para personalizar o visual, edite o arquivo `style.css`.
- Para modificar as interações, edite o arquivo `script.js`.
- Para trocar as fotografias, substitua os arquivos na pasta `imagens` e atualize os caminhos no HTML, se necessário.

## 📚 Sobre The Eltingville Club

Criada por Evan Dorkin, *The Eltingville Club* acompanha quatro fãs de quadrinhos, ficção científica, fantasia, terror e RPG. A obra utiliza humor ácido para explorar o comportamento competitivo, as obsessões e as rivalidades presentes em determinados grupos de fãs.

Além das histórias em quadrinhos, a obra ganhou uma adaptação em animação intitulada *Welcome to Eltingville*, exibida como piloto em 2002.

## 🎯 Objetivo

Desenvolver um site temático utilizando HTML, CSS e JavaScript, praticando organização de conteúdo, criação de layouts, manipulação de imagens e desenvolvimento de funcionalidades interativas.

## ⚠️ Aviso

Este é um projeto de fã, sem vínculo oficial com Evan Dorkin, Dark Horse Comics ou Adult Swim. Os personagens, nomes, marcas e imagens oficiais pertencem aos seus respectivos titulares.
